SCROLL PREVENTION CODE:

Prevents mouse wheel:
  document.addEventListener("wheel", disableScroll, 
    { passive: false });

Prevents keyboard:
  document.addEventListener("keydown", (e) => {
    if (["ArrowUp", "ArrowDown", "PageUp", "PageDown", " "]
        .includes(e.key)) {
      e.preventDefault();
    }
  });

CSS Block:
  html { overflow-y: hidden; }
